# Polymer Trading Management System (PTMS)

Учебный проект Java Backend: управление продажами полимерного сырья.

## Структура Java-кода

- **`src/main/java/com/ptms/`** — текущие классы системы: `Client`, `Order`, `Product`, `Warehouse`, `WarehouseBatch`, сервисы и отчёты. `Main` содержит учебные сценарии запуска.
- **`src/main/java/com/ptms/practice/`** — самостоятельные упражнения из ранних уроков: наследование, интерфейсы, функциональные интерфейсы, Generics и Collections. Они сохранены для повторения, но не относятся к текущей логике отчётности.

Чтобы не мешали в IntelliJ IDEA, можно свернуть пакет **`com.ptms.practice`** в дереве Project. Пакеты — нормальный способ организовывать растущий Java-проект.

## Сборка

```bash
./gradlew build
```

Автоматические тесты в проекте пока не написаны. Локальную сборку после реорганизации нужно проверить в Ubuntu.

> Рефакторинг структуры перенёс учебные примеры в пакет `com.ptms.practice`, не удаляя их. Код основных классов PTMS не менялся.
