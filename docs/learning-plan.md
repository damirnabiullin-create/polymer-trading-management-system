# План обучения Java Backend Developer

**Цель:** подготовка к первой работе Java Backend Developer (уверенный Junior/Junior+, с изучением отдельных тем уровня Middle).
**Старт:** 29.10.2026. **Нагрузка:** 12–15 часов/неделю. **Ориентир:** 8–10 месяцев, сроки корректируются по результатам практики.
**Среда:** Ubuntu, IntelliJ IDEA, GitHub; текущий проект использует Gradle.

Сроки оценочные и частично пересекаются. Kafka и микросервисы — после освоения обязательного стека.

## Сквозной проект: Polymer CRM / PTMS

Система управления продажами полимерного сырья: клиенты, товары/марки, заявки, заказы, складские остатки, пользователи/роли, отчётность.

- **V1 — Java Core:** консольные операции и хранение данных в коллекциях.
- **V2 — PostgreSQL:** схема БД, SQL, сохранение данных.
- **V3 — Spring Boot:** REST API и слои controller/service/repository.
- **V4 — Production-подход:** безопасность, валидация, тестирование, логирование, Docker, документация.

## Формат обучения

Теория → короткий пример → самостоятельная задача → code review → закрепление.
Одна практическая задача за раз; готовое решение — только после попытки или по прямой просьбе. Темы считаются освоенными по практике, а не по прочтению. Регулярное повторение и мини-собеседования.
